# ミニ掲示板アプリ - Flask学習用

## 📚 このアプリについて

Flask初心者向けの教育用ミニ掲示板です。
20分以内で全体像を理解できるシンプルな構成になっています。

## ✨ 機能

- 投稿一覧の表示
- 新規投稿の追加
- 投稿後の自動リダイレクト

## 🚀 起動方法

```bash
# Flaskをインストール（初回のみ）
pip install flask

# アプリを起動
python app.py
```

ブラウザで http://localhost:5000 にアクセスしてください。

## 📖 学習ポイント

### 1. Flaskの基本構造

- `app = Flask(__name__)` でアプリケーション作成
- `@app.route()` でURLとビュー関数を紐付け
- `app.run()` でサーバー起動

### 2. HTTP メソッドの違い

- **GET**: データを取得（投稿一覧を表示）
- **POST**: データを送信（新規投稿を保存）

### 3. テンプレートエンジン（Jinja2）

- `{{ 変数 }}` で値を表示
- `{% for ... %}` でループ処理
- `{% if ... %}` で条件分岐

### 4. データの流れ

```
ブラウザ → Flaskアプリ → テンプレート → ブラウザ
         (request)     (render_template)
```

## 🔧 現在の仕様

- データは **メモリ上のリスト** に保存
- サーバーを再起動すると投稿が消える
- 複数ユーザーで共有される

## 📝 コードの読み方

### app.py の構造

1. **インポート**: 必要なモジュールを読み込み
2. **初期化**: Flaskアプリとデータ領域を準備
3. **ルート定義**: URLに対する処理を記述
4. **起動処理**: サーバーを開始

### なぜリストで保存？

- シンプルで理解しやすい
- Flaskの基本に集中できる
- データベースへの移行が容易

実際のアプリではデータベースを使いますが、
まずは「データをどう扱うか」の概念を学ぶことが重要です。
